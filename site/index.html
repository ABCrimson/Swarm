SWARM Orchestrator

Supervises many coding agents at once. Each worker is a shell on its own pseudo-terminal, optionally in its own git worktree and driving Claude Code or Codex, and everything that happens is an event on one ordered stream backed by a SQLite log.

What The Code Does Today

Each item is true of the code this site was built from and links to the record that pins it. An item tagged Unreleased describes changes made after v0.13.1 and listed under Unreleased in the changelog; the untagged items already held in v0.13.1.

  • One Core, Two Shells

    The Tauri 3 (alpha) desktop app and the headless swarmd daemon both run swarm-core, a Rust library with no Tauri dependency, and dispatch through the same command registry: 36 commands, plus 2 native ones only the desktop has.

    UnreleasedRuntime ModesADR-0001

  • A Daemon You Reattach To

    swarmd serves the registry and the event stream over one WebSocket at /ws, bound to 127.0.0.1:8787 by default and gated by a 64-hex-character token. A client that reconnects replays the log from the last seq it saw, and --serve-ui serves the browser build from disk.

    DaemonADR-0022ADR-0023

  • Two Providers Behind One Trait Pair

    Claude Code runs over its stream-json control protocol and Codex over codex app-server JSON-RPC, both behind the AgentAdapter and AgentSession traits. A session runs in one of three trust tiers, restricted, standard or write_enabled, and bypass modes cannot be constructed.

    UnreleasedAdapter LayerADR-0013ADR-0015

  • Agent Sessions Trust No Repo Configuration

    Claude Code sessions start with --setting-sources "", so a repo's .claude/settings.json cannot run an apiKeyHelper or redirect the CLI. SWARM appends only the repo's permissions.deny entries: a repo can narrow a session and nothing else. Both adapters look for the CLI on absolute PATH entries only.

    UnreleasedADR-0038

  • A Kill Stops The Session First

    kill_worker marks the worker closing, waits for attaches in flight and shuts the provider session down before it touches the shell or the worktree. When it returns, no session of that worker is registered, still handshaking or still shutting down.

    UnreleasedWorkers And PTYsADR-0040

  • The Event Log Flushes Every Commit

    EventLog::init sets PRAGMA synchronous = EXTRA and PRAGMA fullfsync = 1 on the writer connection, reads both back (neither pragma echoes its value) and fails the open with AppError::EventLog unless they read 3 and 1.

    The cost measured on 2026-10-13 on an ext4 WSL2 disk is about 2 ms per persistent event; native Windows NTFS and macOS are unmeasured.

    UnreleasedADR-0039Event Log Persistence

  • A Git Worktree Per Worker

    A worker spawned with a repo root runs in its own locked git worktree on a fresh swarm/ branch. Removal never forces: a dirty worktree is preserved, and the branch is deleted with git branch -d only when its tip is still the commit it started from.

    Worktree IsolationADR-0007ADR-0008

  • A Ship Chain With Receipts

    A finished worker becomes a real commit, a push of that exact commit (<sha>:refs/heads/<branch>, never forced) and a prefilled compare page. Each attempt ends with exactly one ship_settled receipt, and the compare page is built from the worker's recorded push.

    UnreleasedShip ChainADR-0009

  • The Browser Build Says What It Cannot Do

    Over swarmd, the browser build reads capability flags from its transport. Desktop-only controls are hidden or disabled with “Available In The Desktop App Only” instead of failing.

    UnreleasedWhat The Browser Build Offers

  • React Compiler Through Oxc

    Memoization is left to the React Compiler, run as the Oxc port with a WASI fallback binding. pnpm check:compiler fails the build when key components ship uncompiled.

    UnreleasedADR-0032

  • Temporal For Dates And Times

    Dates and durations use Temporal and Intl, with no date library. WebKit webviews ship without Temporal, so src/boot.ts installs temporal-polyfill before the app loads.

    UnreleasedADR-0031
